# Chapter Reference Directory

This directory contains reference documentation for the chapter structure.

## Quick Navigation

All chapter content has been moved to individual `chap_*` directories. Each chapter directory now contains:
- `chapter.txt` - Full chapter text from the book
- `README.md` - Chapter overview and workspace for notes
- Subdirectories for your code exercises

## Documentation Files Here

- **INDEX.md** - Quick reference listing all chapters with line counts
- **README.md** - This file

## Chapter Directories

Navigate to the chapter you want to work on:

```bash
cd ../chap_3   # Chapter 3: Common Programming Concepts
cd ../chap_4   # Chapter 4: Understanding Ownership
# ... etc
```

Each chapter is now self-contained with both the reference material and your code exercises in one place.
